# labs

Small toy projects, built and written up as I go — mostly AI-assisted builds using Claude Code. Each subfolder is one self-contained thing.

## Entries

- [`usage-status`](./usage-status) — a VS Code extension that shows Claude plan usage (session + weekly) as a live status bar graph, reading the Claude desktop app's local usage cache.
- [`ripple`](./ripple) — a greyscale, etch-a-sketch-style water ripple simulation with a generative ambient drone; click to drop, open `index.html` in any browser.
- [`life`](./life) — Conway's Game of Life as a rule laboratory: the classic B3/S23 plus a live-editable rulestring (HighLife, Day & Night, Seeds, Maze, Diamoeba…) and a stamp palette of the canonical patterns, on a wrapping torus grid. Open `index.html` in any browser.
